# AI-Python Project

This is a starter Python project created inside the `AI-Python` workspace.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -U pip
pip install -e .
```

## Run the app

```bash
python -m ai_python_app
```

## Entry point

The package exposes a command-line script:

```bash
ai-python-app
```
